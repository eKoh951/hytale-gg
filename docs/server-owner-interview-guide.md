# Hytale Server Owner Interview Guide

**Goal:** Understand how server owners attract players, what marketing works, and what features they need in a directory

**Target Respondents:** 20-30 Hytale/Minecraft server owners (mix of small, medium, large servers)

**Format:** 20-minute semi-structured interview (can be done via Discord voice/video or written)

**Incentive:** Free premium listing on hytale.gg when launched

---

## Section 1: Server Background (5 min)

### Q1: Tell me about your server
*Open-ended warmup*

**Probes:**
- When did you launch?
- What's your current player count?
- What makes your server unique?
- What's your server type? (Survival, PvP, Roleplay, etc.)

**Why this question:** Builds rapport, establishes context for later answers.

---

### Q2: How many active players do you have?
*Specific metrics*

- Daily active users: _____
- Monthly active users: _____
- Peak concurrent players: _____
- Average session length: _____

**Why this question:** Quantifies server size for segmentation analysis.

---

## Section 2: Player Acquisition (10 min - CRITICAL)

### Q3: How do NEW players currently find your server?
*Open-ended first, then probe*

**After initial answer, probe:**
- What percentage comes from each source? (rough estimate)
- Which source brings the BEST quality players? (most engaged, longest retention)
- Which source brings the most volume?

**Why this question:** Gets real data on discovery channels from those tracking it closely.

---

### Q4: Rank these player acquisition channels by effectiveness for YOUR server
*Force ranking - most effective to least effective*

**Channels to rank:**
- [ ] Server directory websites
- [ ] YouTube videos/sponsorships
- [ ] TikTok videos
- [ ] Discord partnerships/ads
- [ ] Reddit posts/ads
- [ ] Twitter/X posts
- [ ] Instagram posts
- [ ] Twitch streams
- [ ] Word of mouth/friend referrals
- [ ] In-game server browser
- [ ] Google search/SEO

**Follow-up:** "Why did you rank [top choice] as most effective?"

**Why this question:** Forces prioritization, reveals what actually works (not theory).

---

### Q5: What have you STOPPED doing because it didn't work?
*Learn from failures*

**Probes:**
- What marketing channels did you try that failed?
- What directory websites didn't bring players?
- What was a waste of time or money?

**Why this question:** Negative data is as valuable as positive - tells us what NOT to do.

---

### Q6: If you could only invest time in ONE marketing channel, which would it be and why?
*Ultimate forced choice*

**Why this question:** Reveals true priorities when resources are constrained.

---

## Section 3: Current Directory Usage (5 min)

### Q7: Which server directory websites do you currently use?
*List all they use*

**For EACH directory they mention, ask:**
- How satisfied are you with it? (1-5 scale)
- What do you like about it?
- What frustrates you about it?
- Do you pay for premium listings? If yes, why? If no, why not?

**Why this question:** Competitive intelligence on what works/doesn't work.

---

### Q8: What's the BIGGEST problem with current server directories?
*Single biggest pain point*

**Probes if needed:**
- Fake servers/bot votes?
- Hard to stand out?
- Expensive premium listings?
- Poor mobile traffic?
- Bad UI/UX?
- Outdated information?
- No integration with Discord/social?

**Why this question:** Identifies opportunity gaps we can fill.

## Section 5: Player Priorities (Validation)

### Q11: When players join your server for the first time, what do you think they care about MOST?
*Owner perspective on player priorities*

**Ask them to rank:**
1. _____
2. _____
3. _____

**Probes:**
- How do you know this? (data, feedback, intuition?)
- Do you survey your players?
- What makes players STAY vs LEAVE?

**Why this question:** Compare owner perception vs actual player data from player survey.

---

### Q12: What's the #1 reason players LEAVE your server?
*From owner's observation*

**Probes:**
- How do you track this?
- Do you do exit surveys?
- What patterns have you noticed?

**Why this question:** Validates player pain points from different perspective.

## Interview Distribution Strategy

### How to Find Server Owners

**1. Direct Outreach (Best Quality)**
- Message owners of top servers on existing directories
- Reach out in r/admincraft, r/hytaleservers
- Post in server owner Discord communities
- Contact through server Discord servers

**2. Incentivize Participation**
- Offer free premium listing when hytale.gg launches
- Share aggregate research findings
- Early access to analytics dashboard

**3. Target Mix**
- **5-10 small servers** (< 50 daily players)
- **10-15 medium servers** (50-500 daily players)
- **5-10 large servers** (500+ daily players)

**Why this mix:** Different sizes have different needs and budgets.

---

## Analysis Plan

### Discovery Channel Analysis
- Calculate weighted effectiveness scores
- Compare small vs medium vs large server patterns
- Identify "hidden gem" channels (low competition, high quality)

### Pain Point Analysis
- Rank directory problems by frequency mentioned
- Identify must-fix vs nice-to-have
- Compare to player pain points for alignment

### Feature Prioritization
- Use MaxDiff scoring to rank features
- Segment by server size (small/medium/large)
- Cross-reference with willingness to pay

### Pricing Validation
- Calculate average willingness to pay
- Identify price sensitivity by server size
- Determine feature bundles for different tiers

---

## Success Metrics

**Interviews are successful if:**
- ✅ 20+ server owners interviewed
- ✅ Mix of small/medium/large servers
- ✅ Clear ranking of effective acquisition channels
- ✅ Validated SaaS pricing ($10-30/mo range)
- ✅ Identified top 5 must-have features
- ✅ Discovered at least 2-3 unexpected insights

---

## Key Questions We're Answering

1. **How do players ACTUALLY find servers?** (from those who track it)
2. **Which marketing channels work best?** (effectiveness ranking)
3. **What do server owners hate about current directories?** (opportunity gaps)
4. **What features would owners pay for?** (SaaS validation)
5. **What's the willingness to pay?** (pricing validation)
6. **What are we missing?** (blind spots in our assumptions)

---

## Interview Tips

### Do's
✅ **Let them talk** - Don't interrupt interesting tangents  
✅ **Ask "why"** - Dig into their reasoning  
✅ **Take detailed notes** - Capture exact quotes  
✅ **Build rapport** - Show genuine interest  
✅ **Stay neutral** - Don't pitch hytale.gg yet  

### Don'ts
❌ **Don't lead the witness** - Avoid "Don't you think X?"  
❌ **Don't sell** - This is research, not sales  
❌ **Don't rush** - Let silences happen  
❌ **Don't assume** - Verify every assumption  
❌ **Don't skip probes** - Always ask follow-ups  

---
