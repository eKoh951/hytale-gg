# hytale.GG Brand Guidelines

Official brand identity documentation for hytale.GG.

---

## Logo

### Logo Variants

#### Full Logo (hytale.GG)
- **File**: `public/hytale-gg.png`
- **Elements**: "hytale" + grass block + "GG"
- **Use for**: Website header, marketing materials, video intros/outros, large displays

#### Short Logo (h.GG)
- **File**: `public/h-gg.png`
- **Elements**: Voxel "h" + grass block + "GG"
- **Use for**: Favicon, social media profiles, compact spaces, watermarks

#### Source File
- **File**: `public/h_gg_voxel_constructed.psd`
- **Format**: Adobe Photoshop (editable)

### Logo Usage Guidelines

#### Clear Space
Maintain clear space around the logo equal to the height of the grass block on all sides.

#### Minimum Sizes
| Variant | Digital (min width) | Print (min width) |
|---------|---------------------|-------------------|
| Full Logo | 200px | 2 inches |
| Short Logo | 80px | 0.75 inches |

#### Do's ✅
- Use the logo on dark backgrounds (#1F2937 or darker)
- Use the logo on light backgrounds (#F9FAFB or lighter)
- Maintain aspect ratio when scaling
- Use provided PNG files for digital applications

#### Don'ts ❌
- Don't rotate the logo
- Don't change the colors
- Don't add effects (drop shadows, glows, gradients)
- Don't distort or stretch
- Don't place on busy backgrounds without a backdrop
- Don't separate the elements (h, grass block, GG must stay together)
- Don't recreate the logo with different fonts

### Icon Design

For favicon and small icons, use the **short logo (h.GG)** or a simplified version:
- Voxel "h" with grass block
- Remove "GG" text if too small to read (below 32px)
- Ensure grass block remains visible
